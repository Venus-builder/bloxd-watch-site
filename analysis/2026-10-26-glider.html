🪂 解析レポート: グライダーの新エンチャント

2026年10月26日の更新(ビルド cnty9)で入った、グライダー用のエンチャント3種類の効果を、ゲームのプログラムの式から数字にしました。

✅ 結論(いちばん知りたい数字)

ロケット花火のクールダウン: レベルごとに 約15%ずつ(掛け算で)短くなる。レベル1で −15.0%、レベル2で −27.8%、レベル3で −38.6%。
ロケット花火のブースト: レベルごとに +15%ずつ強くなる。レベル1で +15%、レベル2で +30%、レベル3で +45%。
滑空の速度: レベルごとに 最高速度に +2。レベル1で +2、レベル2で +4、レベル3で +6。割合にすると、木のグライダー(基準13)でレベル3なら約 +46%、ダイヤ(基準25)でレベル3なら +24%。

🔎 もう少し詳しく

クールダウン(短くなる割合)

レベル L のとき、元の時間に 0.85 を L 回掛けます(15%ずつ減る掛け算)。足し算ではないので、レベルが上がるほど1段あたりの減り方は小さくなります。

連続で使える回数に直すと、基準の「1秒に1回」に対して、レベル1で約 1.2 倍、レベル2で約 1.4 倍、レベル3で約 1.6 倍(1秒あたり)です。

レベルごとの「元の時間に対する割合」: 1: 85.0% / 2: 72.2% / 3: 61.4% / 4: 52.2% / 5: 44.4% / 6: 40.0% / 7: 40.0%(下限は 40%。レベル6以上で頭打ち)

ブースト(強くなる割合)

レベル L のとき、押し出す力が (1 + 0.15 × L) 倍になります。足し算なので、1レベルごとに同じだけ(+15%)増えます。上限は2倍(+100%)で、レベル7で到達します。

レベルごとの倍率: 1: 115.0% / 2: 130.0% / 3: 145.0% / 4: 160.0% / 5: 175.0% / 6: 190.0% / 7: 200.0% / 8: 200.0%

滑空の速度(最高速度ボーナス)

レベル L のとき、ボーナスは 2 × L(上限 10。レベル5で頭打ち)です。ゲームの資料(スタジオの説明)によると、グライダーの基準の最高速度は、木 13、鉄 17、金 21、ダイヤ 25 です。ボーナスが、この最高速度にそのまま足されると仮定すると、次のようになります。

🎲 エンチャントはどうやってつくか

  • エンチャントの対象は、グライダー(木・鉄・金・ダイヤのハンググライダー)です。つく可能性があるのは、この3種類だけです。
  • エンチャントの階層(Tier 1〜5)が高いほど、「ランダムに1つ選んでレベルを+1する」回数が増えます。Tier 1 なら1回、Tier 5 なら5回です。
  • ランダムにつく場合、1種類のレベルは最大 3 までです(3に達した種類は、それ以上は選ばれません)。
  • たとえば Tier 5 のグライダーなら、合計5レベルが3種類に振り分けられます。1種類に最大3レベル、残りの2レベルが別の種類、という組み合わせが、1つの効果を最大にした場合です。
  • プログラム上の上限(クールダウンのレベル6、ブーストのレベル7、速度のレベル5)は、コマンドや特別な方法で高いレベルをつけたときのための安全装置と見られます。ふつうに遊んでいて届くのは、レベル3までです。

出典: エンチャントを決める処理(階層ごとの回数 {"Tier 1":1 … "Tier 5":5}、1種類の上限 3)と、グライダーのエンチャント一覧 Glider: ["Firecracker Cooldown","Firecracker Boost","Gliding Speed"]。

🚀 ロケット花火の使い方(関連する仕様)

  • ブーストは、ハンググライダーを手に持って滑空中に、ロケット花火(Firecracker)を持っていると使えます。1回につき花火を1個消費します(クリエイティブモードでは消費しません)。
  • ブーストの向きは、見ている方向(水平方向が中心)です。押し出された勢いは、一定時間(約100ティック)かけて普通の滑空に戻ります。
  • クールダウン中は、花火を使えません。画面の真ん中あたりにバーが出ます。

🧪 今回の更新のその他の解析

  • ほかのエンチャントの式は変わっていません。弓、つるはし、斧、鎧などの、既存の式(クイックチャージ、矢の速度、ダメージ計算など)を新旧で比べましたが、数字は同じでした。今回の更新で増えた式は、グライダーの3つだけです。(調べたのは、この式の部分だけで、アイテムの性能値すべてではありません。)
  • Build a Factory 2 の「Islands」は、画面(コアの中の「Islands」ボタン)のプログラムが入っています。持てる島の数は、サーバーから送られる値(baf2IslandsMax)を使うので、クライアントのコードからは分かりません。
  • 「立て看板(Standing Noticeboard)」は、ブロックとしてプログラムに残っています。辞書(翻訳)から表示名の項目が消えただけです。
  • 動物の鳴き声の音声データは、本体ファイル(main.js)から消えていましたが、音の名前の一覧(スタジオの資料)には残っています。データの置き場所が変わっただけの可能性が高いです。
  • 公式のお知らせ(ゲーム内のニュース一覧)には、まだこの更新の項目は載っていません。最新の項目は 10月21日の「Skyblock Official Trailer」でした。

⚠ このレポートの限界

  • ゲームを実際に遊んで測ったものではありません。ゲームのクライアント(ブラウザに配られるプログラム)の式と設定値から計算しています。
  • サーバーが、クライアントと違う式で判定している可能性があります(特にクールダウンとブーストは、サーバー側でも確認されるはずですが、そのコードは見られません)。
  • 入手方法(どの階層のエンチャントで、どう出るか)は、サーバー側の情報なので分かりません。
  • 新機能なので、今後の更新で数字が変わる可能性があります。変わったときは、更新ウォッチが検知します。
