Bloxd スキンビューア 実素材版

bloxd.io の配信 JS に同梱されていた公式プレイヤーモデル(Player_Model.glb)と公式テクスチャアトラス(Player_Atlas.png)をそのまま抽出し、ゲームと同じ「コスメ層 + アトラスUV」方式で描画するデモです。表示中のキャラは公式テクスチャの生データです。

①素材配信JS内のbase64から実アトラス(2048×2048・660部品)と実GLBモデルを抽出
②展開GLBはDraco圧縮 → 実ジオメトリ・実UV・ノード階層を復元
③描画skin→head→eyebrows→eyes→body→legs→shoes の層で全メッシュを重ね描き(αテストでマスク)
④出力透過PNGで保存(toDataURL)
⚙ コントロール

右手/左手を切替えてアイテムを持たせ、スライダーで回転・位置・大きさを自由に調整(左手は鏡像配置)。値は手ごとに保存されます。

スライダーで全関節を自由に回転(X=前後 / Y=ひねり / Z=左右への開き、°)。プリセットを選ぶとスライダーに値が反映されます。ドラッグで視点回転・ホイールでズーム。

スキン=ゲーム内 Characters → Default の8人(実テクスチャ)。選ぶと各部品のコスメ名(body_4_3 等)のアトラスセルが切り替わります。

防具:公式モデル内蔵の実メッシュ+バンドル埋め込みの実テクスチャ(Player_Armour.png 4096×64)。素材は公式の順序で、エンジンと同じUV式 u=(uv.x+素材idx)/64 でサンプリング。αテストで顔開口部も透過します。

プレイヤーのスキンを取得:bloxd内 F12 → Network の get-player-profile レスポンス(JSON)や updateMyCosmetic をコピーして貼り付け「反映」。コスメ名(skin_0_5 等)を直接書いてもOK。

公式モデル内蔵モブ(バンドル内の実GLB+実アトラス)。表示中はプレイヤー系タブが一時無効になります。「歩かせる」は足・腕を振る簡易アニメ。

スキン画像は現在のプリセットの各部品セルを1枚に並べたものです。

調査で分かった Bloxd の実装(実データ確認済み)

  • プレイヤーモデルは Player_Model.glb(32メッシュ・Draco圧縮・blockbench_export)。頭は9×9×9テクセル、腕・脚は3セグメント構造で、目・眉は顔の前面に貼る独立プレートメッシュ。
  • 全コスメ部品の実テクスチャは Player_Atlas.png(2048×2048)に64pxセルで660個格納され、配信JSに base64 で同梱されています。ゲームも同じファイルを getTexture("Player_Atlas") で使用。
  • 外見は skin/head/eyebrows/eyes/body/legs/shoes/back/hat のコスメ名(例 body_4_3)で指定され、描画は各層のセル原点をUVに加算して全メッシュを重ね描き・αテストでマスクする方式(本デモと同じ)。
  • ポーズは ArmLeftMesh 等のノードを関節ピボットで回転(公式APIの api.setPlayerPose も同原理)。まばたき・歩行はエンジン側でUV/頂点をアニメさせる別実装。
  • なお「プレイヤー名 → スキン取得」API(social9.bloxd.io/social/get-player-profile)は認証必須(401実測)のため非公開のままです。本ページは公開素材だけで動いています。
