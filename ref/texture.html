テクスチャパックの作り方・一覧・歴史

公開リポジトリのクローンから分かった、パックの作り方と一覧、更新の歴史。画像などの中身は載せていません。

このページは、bloxd.io のテクスチャパック(見た目の差し替えデータ)の、作り方と、パックの一覧、更新の歴史をまとめたものです。画像・モデル・CSS の中身は、公式と各作者のものなので、置いていません。名前・日付・数だけを載せています。

1. 元の場所

公開の GitHub リポジトリ Bloxdy/texture-packs(公開、フォーク約 285。2026-11-19 に、GitHub の API で存在を確認)。最後の更新は、2026-11-09。確実

2. パックの作り方(README の要約)

部品置き場所できること
テクスチャtextures/名前.png同じ名前の画像で上書き。ブロックと、持ち物のアイテムの両方に効く。
モデルmodels/名前.glb同じ名前の 3D モデル(glb)で上書き。
空(スカイボックス)skyBoxes/名前/ に 6 面の画像default / interstellar / space_blue / space_lightblue / space_red を上書き。ただし、今のゲームは default だけ使い、ほかは、BloxdHop だけが使う、と README にある。
CSScss/名前.css画面の見た目(色・フォント・ホーム背景)を変える。
  • ゲームが読むのは、画像を base64 にした JSON(_json/パック名.json)。フォルダを直したら、npm run update-pack -- パック名 [--bump] で、作り直す。
  • --bump でバージョンを 1 上げると、遊ぶ人の保存済みのパックが、自動で更新される。ゲーム側の knownTexturePackLatestVersion も、上げる必要がある、と README にある。
  • 作るのに使える道具として、Piskel(ドット絵)、voxel-builder、skybox-generator が紹介されている。

5. 使い道・注意

  • 過去の版は、リポジトリの履歴(git show コミット:パス など)で取り出せる。画像そのものは、このサイトには置かず、非公開の保存先に、一式をしまってある。
