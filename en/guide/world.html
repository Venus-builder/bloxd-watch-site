🌍 Handy info: how worlds are generated

Ores, chest contents, biomes and ruins, read from the terrain-generation program ("procGen" worker) that the game (build sn3sfj) serves to your browser.

With the 2026-11-11 update (build 7rp1w) the terrain-generation program (the procGen worker) stopped being served and changed to another form (wasm), so the ore table and the list of ruins cannot be read right now. The chest probabilities and the biome table are still the values read earlier (as of build v98qt8) and may differ in the current game.

⚠️ Please read this first

Terrain generation runs in your browser, so its numbers are served in full. What is listed here is numbers read from the code, not things I confirmed by playing. The confidence is given per item. The units of numbers such as "likelihood" cannot be stated from the code, so treat them as "bigger means more likely". Damage calculations, enemy health and so on live on the server and are not listed here.

⛏️ Ores

Ores are scattered as vein centres, and each centre is filled as a flat disc (in the code, one vein is made at a single height). Ores are only placed below the ground surface.

OreVein height (Y) rangeDisc radiusSpacing between vein centres (rough)Share of the disc that becomes ore
Could not be read from this build (the code may have changed shape)

Y is the coordinate in the code. The ground sits around Y = 0 and rises and falls with local noise (plains vary by a few blocks, snowy mountains go above 80). For "spacing", a smaller number makes more veins (coal 4, iron 5, gold 10, diamond 13, moonstone 40).
Example: diamond is in the deep range Y -100 to -85, in discs of radius 2, of which only about 28% become ore. Moonstone is exactly one layer at Y -85. Reading the code = certain / the "flat disc" look is unchecked

📦 Chest contents

Chests have a "quality", and for each quality the code decides how many items are drawn from each group and what is likely. The same item can show up several times (each draw is independent). The probabilities below are computed with the same formulas as the code.

🏚️ Ruins and dungeons (chests and mob spawners)

Each structure has a number of chests with quality weights, and mob spawners. A quality weight is "how often that chest becomes that quality" (for example Uncommon 2 and Rare 1 means 2:1). Which biome a structure appears in is set per biome (snow ruins in the frozen wasteland, jungle rocks in the jungle, and so on).

🧭 Summary

  • To find diamonds, go deep, to Y -100 to -85. Gold is at -100 to -75, iron at -80 to 15, coal at -60 to 40. Moonstone is a single layer at -85 with wide spacing (very rare), so it is a matter of luck.
  • For strong gear, look at Epic and Legendary chests (large stone ruins, dungeons, large snow ruins).
  • This page is rebuilt automatically at every game update (the numbers are re-read from the program each time).
