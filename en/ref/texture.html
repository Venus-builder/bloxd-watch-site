Texture packs: how they work, the list and their history

How packs are made, the list, and the update history, from a clone of the public repository. Image contents are not included.

This page covers how texture packs (replacement look data) for bloxd.io are made, the list of packs, and their update history. The contents of images, models and CSS belong to the official team and each author, so they are not placed here. Only names, dates and counts are listed.

1. Where it lives

The public GitHub repository Bloxdy/texture-packs (public, about 285 forks; its existence was confirmed through the GitHub API on 2026-11-19). Last updated 2026-11-09. Certain

2. How to make a pack (summary of the README)

PartWhereWhat it does
Texturestextures/name.pngOverrides the image of the same name. Works for blocks and for inventory items.
Modelsmodels/name.glbOverrides the 3D model of the same name (glb).
Sky (skybox)skyBoxes/name/ with 6 face imagesOverrides default / interstellar / space_blue / space_lightblue / space_red. The README says the game currently uses only default and the others are used only by BloxdHop.
CSScss/name.cssChanges screen looks (colours, fonts, the home background).
  • The game reads a JSON (_json/packName.json) with images encoded in base64. After editing the folder, rebuild it with npm run update-pack -- packName [--bump].
  • --bump raises the version by 1 so players' saved packs update automatically. The README says knownTexturePackLatestVersion in the game must be raised too.
  • Tools suggested for making packs: Piskel (pixel art), voxel-builder and skybox-generator.

5. Uses and cautions

  • Old versions can be recovered from the repository history (git show commit:path and so on). The images themselves are not placed on this site; a full copy is kept in a private store.
  • Each pack belongs to its author. Redistributing or reusing it elsewhere needs the author's permission. Only names and counts are listed here.
  • Matching against the official build's list of overridable names has not been done yet. Unknown
