What the labels mean

LabelMeaning
CertainIt is written in the code, or I observed it myself. The build and date are given.
GuessRead from code or text, but the real behaviour has not been checked.
UnknownThe client has no number for it; it is probably on the server (final damage, enemy health, and so on).
