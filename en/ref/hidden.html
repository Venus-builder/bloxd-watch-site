Hidden games (games not shown on the home screen)

Games that are not on the home screen (in development, limited-time or for testing), separating what was checked from what was not.

This page collects games that are not shown on the home screen. Checked on 2026-11-12 (build 31kiid). "The page exists" and "I could join a lobby" are things I confirmed in a real browser. For things that are only "in the code", I have not checked whether they are playable.

3. Looking for in-development games from the browser Certain

  • The list of game names in the code (an array) has 120 names in total (including variants). Those not shown directly on the home screen are the Duels family, Bridge, test games, Skyblock's internal modes (hub / dungeons / farming / mining / fishing / combat / skills_test_gym), special forms of classic (2d / skyGrid / anarchy / creativeFlat / playerSchematic), and the extraction maps (match / desert / winter / training).
  • preprod.bloxd.io and staging.bloxd.io currently return the same build as production (31kiid). So in-development games cannot be seen from there right now (the document below says they were different builds in late 2026-10). Note: a later check showed preprod lagging behind production at times (for example on 2026-11-14), so "same build" holds only at the moments checked.
  • Whether a game appears in the home list is decided by per-site settings (bloxd.io / staging / K12 and so on). The K12 edition (bloxdk12) list is also in the code.

Names are case-sensitive (flagCapture opens, but flagcapture and Skyblock do not). Spaces and - do not work either. 4. Critter Trails (a game in development; not in current production) Certain (that it is gone) / supplied material (the contents)

What was checked (2026-11-12): the name "critter" does not appear anywhere in the current build's (31kiid) main.js or its 353 chunks. bloxd.io/game/critterTrails returns to the home screen. So right now there is no code of this game on the official site.
What follows is from supplied material (a PDF, "critter_trails_guide_ja", examining the 2026-10-23 preprod build scftlm). That preprod build can no longer be fetched, so I have not re-checked the source. Some of the Japanese text in the PDF could not be read in my environment, so only the English parts (in-game text, names, numbers) are used.

Overview (from the material): "Critter Trails" is a Pokémon-like RPG in which you catch, raise and battle 55 kinds of creatures (critters). Each has four forms (default / evolved / glimmer / glimmerEvolved), so there are 55 × 4 = 220 pictures. A glimmer (shiny) form is said to have about a 0.18% chance.

How it was found (from the material): it was in two preprod builds (al23et / scftlm) on 2026-10-22 and 23, about 3.4 MB larger (152 3D-model GLBs, 275 PNGs, translations for 55 kinds). The game's name in the config was "Blank Test" (URL /blank-test), and it was in the dev-game list (Set([schematicTester, testGym, critterTrails])).

How it works (from the material; in-game text)

  • Four elements: Fire, Water, Leaf, Earth. There is a "Fire beats Leaf" message (other matchups are unknown within what I could read).
  • Bosses (Keepers): nine. Beating one unlocks things such as new teams. The last area is "The Summit".
  • Shrines and seals: four of each can be read ("Seals X/4"). There are "Sealed / Locked / Not yet" labels.
  • Catching: prompts read "Tap a critter", "Energy", "Catch!" (it reads as lowering health before catching, but Guess). The tool is the Critter Orb (6 tiers: Twig / Stone / Iron / Gold / Diamond / Moon, strength 1 to 6) and a Pouch to hold it (Twig Pouch and 5 more). The catch chance is shown as "Easy catch! / Good chance / Tricky!".
  • Healing and boost items (5): Critter Heal Bloom ("Energy 35%"), Critter Wake Bell ("40%"), Critter Power Pepper ("+25% (15)"), Critter Guard Shell ("-30% (15)"), Critter Quick Feather ("Big move + 2"). The units of the numbers (seconds or counts) and the Japanese descriptions could not be read in my environment, so they are unknown.
  • The material also mentions the Big move, riding (run on land / swim / fly, dig, freeze water into a path (frost), a vine bridge (vines)), a Field Guide, trainer levels (player battles say "Reach Trainer N to battle other trainers. (Opens soon. Keep playing.)", meaning not open yet), and Glimmer Dust (a boss reward).
  • Six menus: Party / Field Guide / Trail / Me (Trainer) / Battles / Settings.

The creatures (from the material; 55 kinds)

Starter partners (choose 1 of 3): Sootpup (Fire) / Finnip (Water) / Mossbun (Leaf), with "Pick your partner!". Rare ones ("A rare beast. Tougher than other critters."): five kinds: Fizzbang (Fire), Whirlbloom (Leaf), Auroray (Water), Sandtock (Earth), Moonwhale (Water).
